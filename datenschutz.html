3. Nutzung der KI-Funktion: Bild-Upload und Code-Erstellung

Du kannst freiwillig ein eigenes Design-Bild im Format PNG, JPG oder WEBP (maximal 12 MB) auswählen. Die Datei wird zunächst in deinem Browser angezeigt. Erst wenn du auf „In Code umwandeln“ klickst, wird das Bild zusammen mit dem Dateinamen zur Verarbeitung an eine Supabase Edge Function übertragen. Ohne diesen Schritt wird das Bild nicht zur KI-Analyse übermittelt.

Die Supabase-Funktion leitet das Bild an die OpenAI API weiter. OpenAI analysiert das Bild und erstellt daraus HTML-, CSS- und JavaScript-Code. Das Ergebnis wird an deinen Browser zurückgegeben und dort für Vorschau und ZIP-Export verarbeitet.

Nach dem derzeit eingesetzten Programmcode speichert CSSGuru das hochgeladene Bild und den erzeugten Code nicht dauerhaft in einer eigenen Datenbank oder einem eigenen Dateispeicher. Die Vorschau und die ZIP-Datei werden im Browser erstellt. Technische Protokolle der eingesetzten Anbieter bleiben davon unberührt.

Bitte lade nur Dateien hoch, die du verwenden darfst. Lade insbesondere keine Ausweisdokumente, Gesundheitsdaten, vertraulichen Unterlagen oder Bilder mit personenbezogenen bzw. sensiblen Informationen hoch, wenn du nicht sicher bist, dass du diese Daten hierfür übermitteln darfst.

Zweck: Bereitstellung der von dir ausdrücklich angeforderten Bildanalyse und Code-Erstellung.

Rechtsgrundlage: Art. 6 Abs. 1 lit. b DSGVO, soweit die Verarbeitung zur Bereitstellung der von dir angeforderten Funktion erforderlich ist. Für die technische Sicherheit und Missbrauchsabwehr kann ergänzend Art. 6 Abs. 1 lit. f DSGVO gelten. Bitte beachte, dass die Nutzung der Upload-Funktion freiwillig ist; ohne Bildübermittlung kann die KI-Konvertierung nicht ausgeführt werden.

4. Supabase als technischer Dienstleister

Für die Annahme der Anfrage und die Ausführung der Serverfunktion wird Supabase verwendet. Das CSSGuru-Supabase-Projekt ist in der AWS-Region Frankfurt (eu-central-1) angelegt. Diese Regionsangabe betrifft die Projektressourcen. Supabase Edge Functions werden standardmäßig global bzw. in einer für die Anfrage geeigneten Edge-Region ausgeführt; deshalb bedeutet die Frankfurter Projektregion nicht, dass jede Verarbeitung der Edge Function ausschließlich in Frankfurt stattfindet.

Supabase erhält im Rahmen der KI-Anfrage das Bild und den Dateinamen sowie technische Verbindungs- und Betriebsdaten. Der derzeitige Programmcode speichert das Bild nicht in einer Supabase-Datenbank oder im Supabase Storage und schreibt den Bildinhalt nicht bewusst in eigene Anwendungsprotokolle. Supabase kann unabhängig davon technische Nutzungs-, Sicherheits- und Betriebsprotokolle verarbeiten.

Weitere Informationen: Supabase Privacy Policy, Supabase Data Processing Addendum und Informationen zu Datenstandorten und Datenübermittlungen.

5. KI-Verarbeitung durch OpenAI

Das ausgewählte Bild wird zur Analyse an die OpenAI API übermittelt. Anbieter ist OpenAI. Für diese Anfrage wird der Parameter store: false verwendet. Nach den Angaben von OpenAI werden Daten, die über die API übermittelt werden, standardmäßig nicht zum Training oder zur Verbesserung der Modelle verwendet, sofern der API-Kunde nicht ausdrücklich einer solchen Nutzung zustimmt.

OpenAI kann Inhalte und zugehörige Informationen dennoch standardmäßig in Missbrauchsüberwachungsprotokollen für bis zu 30 Tage speichern. Längere Speicherungen können in gesetzlich oder sicherheitsbedingt vorgesehenen Ausnahmefällen möglich sein. store: false bedeutet daher nicht, dass keinerlei Verarbeitung oder Protokollierung durch OpenAI stattfindet.

Eine Verarbeitung außerhalb des Europäischen Wirtschaftsraums kann bei der Nutzung von OpenAI und weiteren Dienstleistern nicht ausgeschlossen werden. Informationen zu Datenverarbeitung, Speicherfristen und verfügbaren Übermittlungsmechanismen findest du in den OpenAI API Data Controls, der OpenAI Privacy Policy und den OpenAI Data Processing Terms.

6. Externe Schriftarten und technische Bibliothek

CSSGuru lädt Schriftarten (DM Sans und DM Mono) über Google Fonts. Beim Laden der Schriftarten stellt dein Browser eine Verbindung zu Google-Servern her. Dabei wird insbesondere deine IP-Adresse sowie technische Browserinformationen übermittelt. Anbieter ist Google Ireland Limited bzw. Google LLC. Weitere Informationen findest du in der Datenschutzerklärung von Google und den Hinweisen zu Google Fonts.

Für die Erstellung der ZIP-Datei wird die JavaScript-Bibliothek JSZip von cdnjs.cloudflare.com geladen. Beim Abruf der Bibliothek wird eine Verbindung zum CDN-Anbieter Cloudflare hergestellt; dabei können insbesondere IP-Adresse und technische Verbindungsdaten verarbeitet werden. Weitere Informationen: Cloudflare Privacy Policy.

Diese externen Ressourcen werden bereits beim Aufruf der Website geladen. Wenn du das vermeiden möchtest, kannst du die Website verlassen; die KI-Funktion ist dann nicht nutzbar. Eine spätere lokale Einbindung der Schriftarten und Bibliothek könnte diese externen Abrufe reduzieren.
